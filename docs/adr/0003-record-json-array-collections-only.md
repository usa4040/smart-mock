# 記録するのは JSON 配列の一覧だけ

乗り換えの約束は、配列の create → list である。コレクションとして記録するのは、パラメータ無しの path と末尾が `{id}` の path の対のうち、一覧の成功レスポンスが JSON 配列であるものだけにする。`{ "items": [ ... ] }` のようにオブジェクトで包む一覧は記録せず、example があればそれ、無ければ生成値を返す。

## Considered Options

- 配列のプロパティを一つ選んで、そこだけを記録の一覧にする。どのキーが一覧かは契約が言わない。

## Consequences

包まれた一覧へ POST しても、次の GET には残らない。配列の一覧だけが、create の結果を list で返す。
